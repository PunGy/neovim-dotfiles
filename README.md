# LIM - NeoVim with Lisp

My configuration of NeoVim IDE using Fennel language.

## System Dependencies

- neovim >= v0.11
- [fennel](https://fennel-lang.org/setup#downloading-fennel)
- Nerd font
- Kitty or WezTerm

## Installation

1. Clone the project to `~/.config/nvim`
2. Install all system dependencies
3. Run `./setup.sh`
4. Open nvim
