# SoVIM

My configuration of NeoVim IDE using Fennel language.

## System Dependencies

- neovim >= v0.10
- [fennel](https://fennel-lang.org/setup#downloading-fennel)
- fzf - file search
  - fd - better `find`
  - rg - better `grep`
  - bat - better `cat`
  - chafa - image previewer

## Core plugins

- **Fennel** - [tangerine](https://github.com/udayvir-singh/tangerine.nvim) + [hibiscus.nvim](https://github.com/udayvir-singh/hibiscus.nvim)
- **Code** - lsp + mason + treesitter

## Installation

1. Clone the project to `~/.config/nvim`
2. Install all system dependencies
3. Open nvim
